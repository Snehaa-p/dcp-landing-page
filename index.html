Frequently Asked Questions

What is device control software?

Device control software is a security solution that manages, monitors, and restricts the use of peripheral devices (such as USB drives, external hard drives, and printers) connected to endpoints in an organization. It helps prevent data theft, malware infections, and ensures compliance with data protection regulations by controlling which devices can access corporate systems and what data can be transferred.

What types of devices can Device Control Plus manage?

Device Control Plus supports 17+ peripheral device types including USB storage devices (flash drives, external HDDs), CD/DVD/Blu-ray drives, printers (local and network), modems, network adapters, Bluetooth devices, imaging devices (scanners, cameras), mobile devices (smartphones, tablets), card readers, wireless adapters, and infrared devices.

What is file shadowing and how does it help security?

File shadowing automatically creates mirror copies of all files transferred to or from external devices. These copies are stored in password-protected network shares, providing a complete audit trail for forensic analysis. If a data breach occurs or unauthorized transfers are detected, security teams can review exactly what data was moved, when, and by whom.
